# Messy Python Code Improvement

## Project Objective

Demonstrate how a simple Python script can be refactored to improve readability and maintainability.

## Files

- `messy_code_before.py` — the original short script with unclear variable names.
- `messy_code.py` — the refactored version with a function, descriptive names, documentation, and input validation.

## Improvements

- Replaced unclear variable names with descriptive names.
- Encapsulated the calculation in a reusable function.
- Added a docstring.
- Added validation to reject negative prices.
- Used a `main()` function and an entry-point check.

## Requirements

Python 3.

## Run

```bash
python messy_code_before.py
python messy_code.py
```

Both scripts print the total for the sample prices: `425`.

## Learning Outcome

Practice code readability, refactoring, functions, and basic validation with Python.
